# MCP Server 3002

Simple MCP server with utility tools.

## Tools

- `get-time` - Get current time for a timezone or city
- `generate-password` - Generate a secure password

## Quick Start

```bash
npm install
npm run dev
```

## Endpoints

- MCP: http://127.0.0.1:3002/mcp
- Health: http://127.0.0.1:3002/health
